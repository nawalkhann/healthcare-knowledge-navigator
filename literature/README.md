# Literature

Every source in the Navigator's library, grouped by topic. Answers on the site are drawn only from these documents.

Sources are open-access PubMed Central articles licensed CC BY or CC0, plus CDC guidance pages (US federal works, public domain). The full list is also in [sources.csv](sources.csv).

The library is refreshed weekly by the **Ingest sources** workflow from the searches in [`data/sources.json`](../data/sources.json). This folder is a snapshot from 26 October 2026; regenerate it after the sources change.
